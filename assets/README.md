# assets

Drop these files here — the site references them by name:

| File           | What it's for                                   | Notes                          |
| -------------- | ----------------------------------------------- | ------------------------------ |
| `portrait.jpg` | Your photo in the About section                 | Square, ~800×800px. If missing, the site shows your initials instead — nothing breaks. |
| `resume.pdf`   | Target of the "Download résumé" button          | Any PDF.                       |
| `og-image.png` | Social preview card (Twitter/LinkedIn/Slack)    | 1200×630px.                    |
| `favicon.svg`  | Browser tab icon                                | Already here — edit the letter and color if you like. |
